# Email orders agent (Система обработки писем)

Автоматическая классификация входящих писем: фильтрует только запросы на стоимость и новые заявки клиентов. Запускает сценарии анализа вложений, стандартизации данных и создания готового Excel-файла.

**Цель**: Ускорить обработку в 5 раз, минимизировать ошибки.

## Функции
- Определение типа письма по содержимому.
- Запуск сценария для формирование файла из письма: анализ вложений, замена наименований по справочнику.
- Уточнение данных у оператора.
- Сохранение результата в таблицу
- Роли: менеджеры (по своей почте), админы (все заявки).

## Развёртыввание
Развёртывание осуществляется через `docker compose`:
- `docker compose up -d --build` - запуск релизной версии
- `docker compose --file docker-compose-dev.yml up -d --build` - запуск версии для разработчиков с доступом к api и weui инструментов из `localhost`
Остановка сервиса:
- `docker compose down` - релизная версия
- `docker compose --file docker-compose-dev.yml down` - версия для разработчиков

## Взаимодействие
Доступ к сервису можно получить по адресам:
- `http://localhost/`
- `http://localhost:8000/`
В версии для разработчиков дополнительно:
- `http://localhost:8081/` - интерфейс для работы с БД
- `http://localhost:9001/` - интерфейс облачного хранилища


## Технологии
База данных: Postgresql
Облачное хранилище: S3/MinIO
Проксирование: Nginx
