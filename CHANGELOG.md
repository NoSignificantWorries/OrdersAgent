# Changelog

## [1.3.0] - 2026-06-07
- Добавлена генерация файлов для писем заявок на рассчёт
- Добавлен функционал отправки писем с вложенными файлами
- Реализоана базовая система ролей для юзеров

## [1.2.0] - 2026-06-01
- Добавлена метка архивированных писем для отработанных задач
- Добавлена возможность смены метки архивированных писем
- Добавлена метка прочитанных и непрочитанных писем
- Добавлены вкладки: активные письма и архивированные письма
- Добавлена возможность закрыть текущее письмо

## [1.1.1] - 2026-05-26
- Добавлена возможность смены класса письма на любом этапе

## [1.1.0] - 2026-05-26
### Changes
- Добавлена клонка артикулей для материалов
- Классификация изменена на Random Forest
- Добавлен класс `question`
- Реализована смена класса
- Добавлены разные статусы для писем с разными классами
- Добавлен вывод ошибок
- Добавлена возможность удалять отработанные письма
### Fixes:
- Исправлено обрезание ввода данных в полях материалов при вводе
- Исправлен нерабочий фильтр по статусу писем


## [1.0.0] - 2026-05-13
- Первый тестовый релиз
- Базовая работа с письмами файлами
