# Табличный парсер

## Загрузчик
Загружает таблицы `xls/xlsx` через `xlrd` и `openpyxl` соответственно.
Таблицы могут быть в виде BytesIO (бинарный формат) или Path (путь до файла).
Читаются в формате read-only, без метаданных и информации форматирования.
Ячейки строкового типа не преобразуются, числа float и int упрощаются до int с округлением по нижней границе, пустые ячейки и пустые строки - None, остальные данные преобразуются в строку.

## Разреженная таблица
Ячейки помещаются в таблицу, в которой происходит очистка пустых строк и столбцов, а также ячейки переходят от простого значения в объект-обёртку для возможности независимой обработки.

## Факты и гипотезы
Для парсинга таблиц применим систему построения фактов по имеющимся данным и гипотез, которыми мы располагаем для каждого факта.
То-есть вместо определения полей независимо и дальнейшего парсинга уже распаршенных данных, а также сложной многоэтапной валидации работы парсера мы будем при определении ячейки распростанять по таблице набор связанных с ней фактов и гипотез. По итогу нам достаточно просто ещё раз пройтись по ячейкам и в каждой у нас будет набор связанных с ней данных, остаётся их проверить.
Такой подход потенциально уменшает код, упрощает расширение и парсинг сложных случаев, а также сильно упрощает создание основной логики пуллинга данных.

В главном цикле перебираем ячейки по правилам LR и TD:
- При старте итерации применяем правила для ячейки, если возможно
- Проверяем триггеры для фактов, применяем трансформации данных если нужно и назначаем факты для ячейки
- Получаем набор гипотез для фактов текущей ячейки
- Записываем новые правила

Также существуют правила строк, они действуют на всю строку и конкотенируются с каждыми правилами ячеек в строке.

### Правила:
- Диапазон где правило действует
- Набор гипотез и фактов, которые записываются ячейкам из диапазона

### Парсинг результата:
Факты преобладают над гипотезами, набор определённых фактов = подтверждение роли ячейки, противоречие некоторых фактов = ошибка в ячейке, требуется валидация.

### Возможные триггеры/правила:
#### aufbau
Часть шапки для формата #2.
Триггер - ключевые слова.
Факты:
- Правило строки - строка начала шапки формата #2
- Правило строки - строка-поле
Гипотезы:
- Объект справа - label
- Объект ниже - name

#### name
Часть шапки формата #2.
Триггер - ключевые слова.
Факты:
- Правило строки - строка-поле
Гипотезы:
- Объект справа - label
- Объект ниже - thikness

#### thikness
Часть шапки формата #3.
Триггер - ключевые слова.
Факты:
- Правило строки - строка конца шапки формата #2
- Правило строки - строка-поле
Гипотезы:
- Объект справа - label

#### material
Номенклатура/формула стеклопакета, заголовок.
Триггер - ключевые слова.
Факты:
- Правило строки - строка заголовочная
- Объекты ниже - строки
- Сама ячейка - заголовок
Гипотезы:
- Правило таблицы - таблица формата #1
- Правило строки - только один material в строке

#### amount
Количество стеклопакетов одного формата.
Триггер - ключевые слова.
Факты:
- Правило строки - строка заголовочная
- Объекты ниже - числа
- Сама ячейка - заголовок
Гипотезы:
- Правило строки - только один amount в строке

#### barcode
Штрихкод для пометки стеклопакетов.
Триггер - ключевые слова.
Факты:
- Правило строки - строка заголовочная
- Объекты ниже - числа или строки
- Сама ячейка - заголовок
Гипотезы:
- Правило строки - только один barcode в строке

#### marking
Маркировка для пометки стеклопакетов.
Триггер - ключевые слова.
Факты:
- Правило строки - строка заголовочная
- Объекты ниже - числа или строки
- Сама ячейка - заголовок
Гипотезы:
- Правило строки - только один marking в строке

#### size
Размеры стеклопакета, сложное поле.
Триггер - ключевые слова.
Факты:
- Объекты ниже - тип число или sizes
- Сама ячейка - заголовок
Гипотезы:
- Строка заголовочная
- Объект на ячейку ниже тоже заголовок размера
- Объект справа тоже заголовок размера
- Объекты в колонке справа - числа
- Правило строки - один или два size в строке

#### Тип числа
Просто в ячейке число.
Триггер - тип ячейки числовой.
Факты:
- Сама ячейка - просто число (int)
Гипотезы:
- Правило строки - строка данных
- Самая ячейка - данные размера/количества/штрихкода/маркировки

#### Тип строки
Просто строка (триггер с низшим приоритетом).
Триггер - тип ячейки строчный.
Факты:
- Сама ячейка - просто строка (label)
Гипотезы:
- Сама ячейка - данные номенклатуры/штрихкода/маркировки

#### Тип sizes
Тип ячейки с кортежом размеров стеклопакета.
Триггер - регекс паттерн.
Преобразование - извлечение кортежа.
Гипотезы:
- Правило строки - строка данных
- Сама ячейка - данные размеров
